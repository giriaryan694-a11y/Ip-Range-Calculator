How range notation works

An IPv4 address is four numbers (called octets), each from 0–255, separated by dots — like 192.168.1.10. This tool lets you describe a whole block of addresses at once by giving a range instead of a single number for any octet.

10.10.0-255.101-125
  1. 110 and 10 — fixed numbers, so those octets don't change.
  2. 20-255 — the third octet can be anything, so it contributes 256 possibilities.
  3. 3101-125 — the fourth octet is limited to 25 values (125 − 101 + 1).
  4. 4Total addresses = multiply every octet's possibility count together.
